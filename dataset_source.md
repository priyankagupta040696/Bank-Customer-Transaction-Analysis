# Dataset Source

**Dataset:** Bank Customer Segmentation (1M+ Transactions)\
**Platform:** Kaggle\
**Author:** shivamb

## Dataset Page

https://www.kaggle.com/datasets/shivamb/bank-customer-segmentation

## Project Usage

The dataset is used for educational and portfolio analysis. The
repository does not need to redistribute the full raw dataset. Refer to
the original Kaggle dataset page for source information and applicable
usage terms.

## Dataset Used in This Project

-   File: `bank_transactions.csv`
-   Rows: 1,048,567
-   Original columns: 9
-   Unique customers: 884,265

The analysis was performed in Microsoft Excel using Power Query, the
Excel Data Model, PivotTables, PivotCharts, slicers, and a timeline.
